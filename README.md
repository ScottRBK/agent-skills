# Agent Skills

My collection of reusable skills for AI coding agents.

## Included skills

- [ci-cd](ci-cd/SKILL.md): Create, maintain and verify CI/CD workflows.
- [context7-cli](context7-cli/SKILL.md): Fetch library documentation and manage Context7 skills.
- [creating-eval-harness-evaluations](creating-eval-harness-evaluations/SKILL.md):
  Create evaluations for CLI coding agents.
- [envault](envault/SKILL.md): Supply secrets to commands through envault.
- [grill-me](grill-me/SKILL.md): Explore a topic through detailed questions.
- [hexagonal-architecture-testing](hexagonal-architecture-testing/SKILL.md):
  Check dependency boundaries and prove that the rules catch forbidden imports.
- [hf-cli](hf-cli/SKILL.md): Work with Hugging Face repositories, models, datasets and jobs.
- [humanizer](humanizer/SKILL.md): Rewrite AI-sounding prose while preserving its meaning.
- [interlinked](interlinked/SKILL.md): Confirm an agreed action plan before execution.
- [lavish](lavish/SKILL.md): Create HTML explanations that can be reviewed and annotated.
- [mycelium-architecture](mycelium-architecture/SKILL.md):
  Maintain an architecture overview from a detailed class map.
- [mycelium-mermaid](mycelium-mermaid/SKILL.md):
  Generate Mermaid class diagrams from source code or a saved Mycelium map.
- [playwright-cli](playwright-cli/SKILL.md): Automate browsers and test websites.
- [rust-error-handling](rust-error-handling/SKILL.md): Design and review Rust error handling.
- [show-me](show-me/SKILL.md): Explain topics with concise diagrams and visual examples.
- [test-driven-development](test-driven-development/SKILL.md): Apply test-driven development.
- [writing-great-skills](writing-great-skills/SKILL.md): Write predictable, maintainable skills.

Each skill's instructions are in its `SKILL.md` file. Keep any accompanying references, scripts
and agent metadata with the skill when copying it to another installation.

## Local-only skills

The local `sonarqube-results/` skill is excluded by `.gitignore` and is not part of this collection.
