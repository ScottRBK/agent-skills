# Agent Skills

My collection of reusable skills for AI coding agents.

## Included skills

- `context7-cli`: Fetch current library documentation and manage Context7 skills.
- `creating-eval-harness-evaluations`: Create evaluations for CLI coding agents.
- `lavish`: Build rich, reviewable HTML artifacts.
- `playwright-cli`: Automate browsers and test websites.
- `rust-error-handling`: Design and review Rust error handling.
- `test-driven-development`: Apply test-driven development.
- `writing-great-skills`: Write predictable, maintainable agent skills.

Each skill's instructions are in its `SKILL.md` file. Some skills include additional material in a
`references` directory.
